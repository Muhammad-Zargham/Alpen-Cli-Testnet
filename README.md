⚠️ Safety first (READ THIS BEFORE YOU DO ANYTHING)

Never commit your BIP39 seed, private keys, or any file from ~/.local/share/alpen/ or ~/.config/alpen/ to this repo. Add any backups or secrets to your local .gitignore and never paste them into issues or PRs.

The scripts in /scripts are testnet-only by default. Still, treat them carefully and read before you run.
